# OpenPike Stocks 发布素材

## 一句话

把买点条件、退出边界和判断依据，放进同一个看板。

## 面向谁

想把沪深主板短线观察整理成固定流程、愿意核验资料并登记实际持仓的研究者。当前提供本机源码，优先适合愿意自行安装的用户。

## 60 秒视频

| 时间 | 实拍画面 | 口播 |
|---|---|---|
| 0–8 秒 | 首屏买点与退出提示 | 我做了 OpenPike Stocks：把股票买点条件、持仓退出边界和判断依据，放进同一个看板。 |
| 8–22 秒 | 候选排名、K 线、盘口 | 它会自动检查候选条件。排名高还不够，确认线、证据和风控都需要通过。像现在休市，就明确等待。 |
| 22–35 秒 | 评分构成与阻断原因 | 我更在意它为什么这样判断：哪些条件通过、哪些资料缺失，都直接显示出来。评分也不会被包装成胜率。 |
| 35–47 秒 | 只拍空持仓登记页，不填个人账户 | 登记实际成交后，它会按原失效价、第一压力、持有期限和 T+1 检查退出条件。它只提示，不替你下单。 |
| 47–55 秒 | 策略验证页与档案入口 | 每次判断保留依据。策略改进先做前向验证，再决定是否升级。 |
| 55–60 秒 | GitHub 首页与安装入口 | 源码已经放在 GitHub。欢迎安装、提问题，和我一起把这套观察流程做得更可靠。 |

字幕常驻：研究工具；无证券委托；评分不等于胜率。市场截图注明拍摄日期及休市状态。不要把截图里的股票当作实时推荐。

## 发布文案

我把 OpenPike Stocks 的首个源码预览公开了。

它把三件事放进一个本机看板：买点条件是否满足、已登记持仓是否触发退出条件、每一次判断依据是什么。

条件不齐就等待，资料缺失不补分，规则和输入留档。Mac 用户可以自行构建独立窗口。

当前没有经过验证的胜率，也没有自动下单功能。欢迎愿意自行安装的研究者反馈资料覆盖、可解释性和使用体验。

项目：https://github.com/spikesubingrui-design/openpikestocks
